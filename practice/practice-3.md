# Практическая работа № 3

## Развёртывание приложения с помощью Ansible

### Задание

Написать Ansible-плейбук, который обеспечит доставку и развёртывание веб-приложения из практической работы № 2 на «сервер».

Плейбук должен автоматизировать подготовку окружения, передачу приложения и его запуск на целевой машине.

### Результат

После выполнения плейбука приложение должно быть запущено на сервере и доступно для проверки.

В репозитории должны находиться:

- Ansible-плейбук;
- inventory или пример inventory;
- необходимые шаблоны и переменные;
- инструкция по запуску плейбука.
